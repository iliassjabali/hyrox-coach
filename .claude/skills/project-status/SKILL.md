# Project Status

Summarise where the CM3070 Hyrox Coach project stands.

## Steps

1. Read `docs/plan.md`.
2. Determine the **current phase** from the "Status snapshot" and the first phase
   with unchecked (⬜) tasks.
3. Report, concisely:
   - Current phase and the next graded milestone (with its weight).
   - Count of done (✅) vs remaining (⬜) tasks **in the current phase**.
   - The next 3–5 actionable tasks (by `#`, respecting their `Dependency` column —
     don't suggest a task whose dependency is unmet).
   - Any 🎯 deadline-bearing milestone coming up.
4. If `docs/journal.md`'s latest week is behind the current phase week, flag that
   the journal needs an entry (it feeds exam Q3).

Do not modify files — this is a read-only status report.
