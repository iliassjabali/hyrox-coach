# Rubric Self-Check

Run the CM3070 14-item rubric against the current submission artefacts before
submitting. This is a gate, not a rewrite — report gaps, don't paper over them.

## The 14 criteria

1. Template (CM3020 Idea 1) clearly stated, connection evident throughout
2. Report clear, well formatted, coherent
3. Displays knowledge of area (lit review)
4. Critically evaluates previous work
5. Proper citation and referencing (IEEE, **no fake references**)
6. Design clear and high quality
7. Project concept justified by domain
8. Work plan detailed and feasible
9. Evaluation strategy appropriate
10. Feature prototype high quality
11. Feature prototype technically challenging
12. Demonstration effective
13. Evaluates prototype + shows improvements
14. Innovation and excellence (exceptional criteria)

## Steps

1. Ask which submission is being checked (preliminary / draft / final) — criteria
   weighting differs (e.g. preliminary leads on 1–11; final adds 12–14).
2. For each applicable criterion, inspect the relevant artefact (report PDF/TeX,
   `AGENTS.md`, code, eval results, video script) and mark: ✅ met / ⚠️ partial / ❌ missing.
3. For every ⚠️/❌, give a specific, actionable fix referencing the file/section.
4. Apply Reza's banked emphasis: **lead with objective metrics** (criteria 9, 13);
   ensure the lit review covers **both** orchestration and AI-fitness branches (3, 4).
5. Hard-fail loudly on: any unverifiable/fake citation (5), missing word counts,
   or DEI section absent (14 / learning objective).

Output a checklist with the verdict per item and a prioritised gap list. Do not
mark a criterion met without inspecting the actual artefact.
